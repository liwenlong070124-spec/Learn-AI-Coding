# Learn AI Coding

这是一个用于记录和练习 AI 编程学习过程的仓库。

## 项目说明

这个仓库用于记录我从零开始学习 AI 编程的过程，包括：

- Git 和 GitHub 的基本使用
- 前端静态页面开发
- HTML、CSS、JavaScript 的基础练习
- GitHub Pages 的部署与发布
- 学习中常用的项目结构与规范整理

## 仓库内容

- `my-web/`：静态网站项目，包含首页、作品页和博客页
- `git-guidelines/`：Git 分支命名和提交规范说明
- `.github/workflows/`：GitHub Pages 自动部署配置

## 学习目标

通过这个仓库，我希望逐步掌握：

- 使用 Git 进行版本控制
- 使用 GitHub 管理代码和项目
- 学习前端基础开发
- 了解部署流程与静态网站托管
- 形成清晰的开发规范和工作流

## 说明

这个项目本质上是一个学习型仓库，内容会随着学习进度不断更新和完善。

它的目标不是追求复杂功能，而是记录从入门到逐步理解 AI 编程开发流程的实际过程。

## 备注

本仓库适合用于：

- 学习 Git
- 学习前端基础
- 学习 GitHub Pages
- 记录自己的编程练习与项目进步
